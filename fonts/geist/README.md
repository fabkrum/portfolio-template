# Geist

A clean sans-serif. In the five styles: Modern (headings and text).

- In a brief's Type table: `"Geist", system-ui, sans-serif`
- Files: Latin letters only, WOFF2, every weight from 100 to 900 in one variable file.
  - `geist-latin-wght-normal.woff2` (29 KB)
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 1.800 (Google Fonts v5).
- Source: the npm package `@fontsource-variable/geist` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource-variable/geist@5.3.0/files/
