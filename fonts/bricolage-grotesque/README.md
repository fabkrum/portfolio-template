# Bricolage Grotesque

A sans-serif with character. In the five styles: Playful (headings).

- In a brief's Type table: `"Bricolage Grotesque", system-ui, sans-serif`
- Files: Latin letters only, WOFF2, every weight from 200 to 800 in one variable file.
  - `bricolage-grotesque-latin-wght-normal.woff2` (40 KB)
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 1.001 (Google Fonts v9).
- Source: the npm package `@fontsource-variable/bricolage-grotesque` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource-variable/bricolage-grotesque@5.3.0/files/
