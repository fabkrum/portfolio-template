# JetBrains Mono

A monospace font made for code. In the five styles: Modern (dates) and Technical (headings, labels, dates).

- In a brief's Type table: `"JetBrains Mono", ui-monospace, Menlo, Consolas, monospace`
- Files: Latin letters only, WOFF2, every weight from 100 to 800 in one variable file.
  - `jetbrains-mono-latin-wght-normal.woff2` (39 KB)
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 2.211 (Google Fonts v24).
- Source: the npm package `@fontsource-variable/jetbrains-mono` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource-variable/jetbrains-mono@5.3.0/files/
