# Newsreader

A serif for headings. In the five styles: Classic (headings).

- In a brief's Type table: `"Newsreader", Georgia, "Times New Roman", serif`
- Files: Latin letters only, WOFF2, every weight from 200 to 800 in one variable file.
  - `newsreader-latin-wght-normal.woff2` (57 KB)
  - `newsreader-latin-wght-italic.woff2` (63 KB): italic
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 1.003 (Google Fonts v26).
- Source: the npm package `@fontsource-variable/newsreader` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource-variable/newsreader@5.3.0/files/
