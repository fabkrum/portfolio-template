# Work Sans

A plain, friendly sans-serif. In the five styles: Bold (text).

- In a brief's Type table: `"Work Sans", system-ui, sans-serif`
- Files: Latin letters only, WOFF2, every weight from 100 to 900 in one variable file.
  - `work-sans-latin-wght-normal.woff2` (49 KB)
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 2.012 (Google Fonts v24).
- Source: the npm package `@fontsource-variable/work-sans` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource-variable/work-sans@5.3.0/files/
