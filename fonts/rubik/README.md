# Rubik

A sans-serif with slightly rounded corners. In the five styles: Playful (text).

- In a brief's Type table: `"Rubik", system-ui, sans-serif`
- Files: Latin letters only, WOFF2, every weight from 300 to 900 in one variable file.
  - `rubik-latin-wght-normal.woff2` (35 KB)
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 2.300 (Google Fonts v31).
- Source: the npm package `@fontsource-variable/rubik` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource-variable/rubik@5.3.0/files/
- Licence: SIL Open Font License 1.1, copyright The Rubik Project Authors, in `OFL.txt`, from https://github.com/google/fonts/tree/main/ofl/rubik. It travels with the font files: keep `OFL.txt` next to them.
- Made by: https://github.com/googlefonts/rubik
