# Literata

A serif made for long reading. In the five styles: Classic (text).

- In a brief's Type table: `"Literata", Georgia, "Times New Roman", serif`
- Files: Latin letters only, WOFF2, every weight from 200 to 900 in one variable file.
  - `literata-latin-wght-normal.woff2` (51 KB)
  - `literata-latin-wght-italic.woff2` (52 KB): italic
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 3.103 (Google Fonts v40).
- Source: the npm package `@fontsource-variable/literata` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource-variable/literata@5.3.0/files/
