# Anton

A tall, condensed display sans-serif. In the five styles: Bold (headings).

- In a brief's Type table: `"Anton", Impact, "Arial Narrow", sans-serif`
- Files: Latin letters only, WOFF2, weight 400 only.
  - `anton-latin-400-normal.woff2` (18 KB)
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 2.116 (Google Fonts v27).
- Source: the npm package `@fontsource/anton` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource/anton@5.3.0/files/
- Licence: SIL Open Font License 1.1, copyright The Anton Project Authors, in `OFL.txt`, from https://github.com/google/fonts/tree/main/ofl/anton. It travels with the font files: keep `OFL.txt` next to them.
