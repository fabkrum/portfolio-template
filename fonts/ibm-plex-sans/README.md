# IBM Plex Sans

A sober sans-serif with an engineered feel. In the five styles: Technical (text).

- In a brief's Type table: `"IBM Plex Sans", system-ui, sans-serif`
- Files: Latin letters only, WOFF2, every weight from 100 to 700 in one variable file.
  - `ibm-plex-sans-latin-wght-normal.woff2` (45 KB)
- `font-face.css`: the `@font-face` rules for these files, as `node tools/fonts.mjs` prints them for `site/assets/styles.css`.
- Version: 3.201 (Google Fonts v23).
- Source: the npm package `@fontsource-variable/ibm-plex-sans` 5.3.0 by Fontsource, which builds it from Google Fonts, downloaded from https://cdn.jsdelivr.net/npm/@fontsource-variable/ibm-plex-sans@5.3.0/files/
- Licence: SIL Open Font License 1.1, copyright IBM Corp., in `OFL.txt`, from https://github.com/google/fonts/tree/main/ofl/ibmplexsans. It travels with the font files: keep `OFL.txt` next to them.
