# The Analyst's checkpoint

The end of the Analyst's block: the template as it ships. The Analyst writes only your own files, `site/content.json` and `docs/spec.md`, which a checkpoint keeps. So this folder holds the site of the template, with the sample person, Ada Example, in `site/content.json`, the sample spec and the default design brief. They go in only where you have none of your own.
